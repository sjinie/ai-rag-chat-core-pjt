# AI 코어 프로젝트 2회차 — RAG 기반 도메인 지식 서비스 요구사항

> 출처: `docs/AI코어프로젝트_2회차_요구사항정의서.pdf` — 영화(Movie Lab) 예시는 제외하고 도메인 중립으로 정리.
> 도메인: **(미정)**

## 0. 도메인 선정 조건 (1일차 16시까지 확정)

세 조건을 모두 만족해야 하며, 기한 내 미충족 시 영화 팩으로 전환된다.

| 조건 | 내용 |
|---|---|
| **항목 메타데이터** | 이름과 속성을 가진 항목 **약 100건 이상** |
| **외부 문서 출처** | 항목마다 연결되는 설명 문서 (한국어 위키백과 권장, 공공데이터·PDF 허용). 출처와 이용 조건 기록 |
| **근거가 필요한 질문** | 근거 없이 답하면 틀리거나 위험해지는 질문 **3개 이상** |
| 위험 도메인 여부 | 건강·금융 등이면 "전문가 조언을 대신하지 않음" 면책 문구 필수 |

## 1. 기획 단계에서 정할 것 (6가지)

1. **도메인 확정** — 위 조건 충족 근거를 함께 기록
2. **항목 텍스트 설계** — 항목 1건을 어떤 속성으로 묶어 하나의 검색 텍스트로 만들지. 사용자가 무엇으로 찾을지가 기준이며, 빠진 속성으로는 검색되지 않는다.
3. **컬렉션과 메타데이터** — 컬렉션 2개(항목 메타 / 외부 문서). 외부 청크에 문서 제목, 원문 URL, 문서 ID, **항목 ID**(필터용), 관련 항목명, 검색어, 수집일 저장
4. **프롬프트 3개** — ① 검색어 추출(전문가 역할, JSON 출력) ② 후보 문서 선별(제목·요약만 보고 선택) ③ 답변 생성(근거만 사용, 없으면 "확인되지 않음")
5. **검색 설정** — 청크 크기, 중복 길이, Top-k, 검색 방식(유사도/MMR)을 **설정 파일로 분리**. 시작값: 1,000자 청크 / 200자 중복
6. **서비스 기능과 화면** — 도메인 특화 기능 1개 이상, 조건 기반 탐색, 진행 상태·오류·면책 안내

## 2. 기능 요구사항 — 필수 (F2001~F2012)

필수 기능은 수정할 수 없으며, 도메인에 맞게 표현만 바꿀 수 있다.

| ID | 요구사항 | 핵심 조건 |
|---|---|---|
| F2001 | 항목 메타데이터 적재 | 100건 이상 로드, 1건을 색인 텍스트 1개로 구성 |
| F2002 | 메타데이터 색인 (RAG 1) | 임베딩 후 Chroma 적재. **청크 ID = 항목 ID**로 재색인 시 중복 없음. 색인 건수 표시 |
| F2003 | 검색어 추출 (프롬프트 1) | 전문가 역할, 파싱 가능한 출력. **항목 자체를 다룬 문서는 항상 포함** |
| F2004 | 외부 문서 수집 (프롬프트 2) | 후보 검색 → LLM 선별 → 본문과 원문 출처(URL 또는 파일명·쪽) 수집. 항목 자체 문서는 어떤 제외 규칙보다 우선. **이미 수집한 검색어는 재수집 금지**. 외부 호출 제한 시 제공 문서 묶음으로 대체 가능 |
| F2005 | 외부 문서 색인 (RAG 2) | 별도 컬렉션, 청크 크기·중복은 설정값. 청크 ID `항목ID:문서ID:순번`으로 다른 항목끼리 덮어쓰지 않음 |
| F2006 | 근거 검색·병합 | 선택 항목의 메타 청크는 **항상 포함**, 외부 청크는 항목 ID로 범위를 좁혀 유사도 검색 → 병합·중복 제거. Top-k는 설정값 |
| F2007 | 근거 기반 답변 (프롬프트 3) | **LangGraph retrieve / generate 2노드**. 출처 유형(메타/외부) 구분. 근거 없으면 추측 금지 |
| F2008 | 근거 표시 | 주요 주장에 `[근거 N]` 표기. **실제 인용된 근거만** 제목과 원문 링크로 표시. 인용 0건이면 안내 |
| F2009 | 항목 선택·질의응답 | 목록에서 항목 선택 후 채팅. **항목별로 대화 기록 분리** |
| F2010 | 도메인 특화 기능 | 1개 이상. 근거 기반으로 동작하고 근거를 함께 제시 |
| F2011 | 조건 기반 항목 탐색 | 자연어 조건 → 메타 색인 검색 → LLM이 조건에 맞는 항목만 선별 → 선택하면 그 항목 대화로 이동 |
| F2012 | 진행 상태·안내 | 수집·생성 중 상태 표시, 색인 0건·API 키 누락 안내, 위험 도메인 면책 문구 |

| ID | 요구사항 | 핵심 |
